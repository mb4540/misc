The 90-second version

SysML v2 is a ground-up replacement for SysML v1, not an upgrade. v1 was a UML profile — a set of stereotypes bolted onto a software-modelling language. v2 has its own metamodel built on KerML (Kernel Modeling Language), a formal semantic foundation with no UML baggage.

Three things changed that matter commercially:

  • A textual notation. Models are now source code — diffable, reviewable in a pull request, generable by an LLM, parseable by a pipeline. Graphics become a view of the model rather than the model itself.
  • A standard REST API. The Systems Modeling API & Services spec means a model repository is queryable by any tool over HTTP. This is the piece that makes "digital thread" more than a slide.
  • Formal, evaluable requirements. A requirement in v2 is a specialised constraint with typed parameters. It can be checked by a machine, not just read by a human.

OMG approved SysML v2.0 and KerML 1.0 for final adoption in July 2025; the specs were submitted to ISO in March 2026, and KerML 1.1 / SysML 2.1 Beta is in the pilot implementation as of the 2026-04 release.
