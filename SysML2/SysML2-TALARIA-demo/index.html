TALARIA — SysML 2.0 Concept Demo

What the Space Assurance Gateway looks like when the model is a SysML v2 model.

These screens mirror the production TALARIA UI — same design tokens, same shell, same page structures — with SysML 2.0 woven into the places it would actually show up. Everywhere the standard does real work, there is a 1 marker. Click one and it jumps to the explanation panel at the bottom of that page.

Each explanation says what the construct is, and what TALARIA does today without it, so the delta is visible rather than asserted.

Reading this demo

Sign-in is skipped. The Employee Console screens are shown as Sarah Chen (lead engineer); the Customer Portal screens as James Wilson at ProtoPD Customer Corp. The dark bar at the top of every screen is demo chrome, not part of the product.

The project is J9Avionics — TIA Power Board Rev C, 69 part types across 142 instances, in Phase 5 (Detailed Design), against NASA-EEE-INST-002 Class B for a 5-year 550 km LEO mission.

Nothing here requires a server. Open index.html in any browser.

Where this is honest about scope. SysML v2 supplies the language and the protocol. It supplies no derating tables, no radiation models and no screening rules — that content stays Jemba9's. What changes is that the content becomes expressible in a form other tools can read and check.
