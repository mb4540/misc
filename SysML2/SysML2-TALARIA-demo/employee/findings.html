1
verification case — a finding shows its working
The verdict carries the expression that produced it, the values that were bound, and the clause it came from. A reviewer does not have to trust the number; they can read the evaluation.
Today: derating_finding stores ratedValue, deratedLimit, actualValue, marginPercent and a ruleId. All the inputs are there, but the rule itself is a factor, so the finding cannot show the expression — only the arithmetic result.
2
Findings resolve to individual part usages
Because each reference designator is a real usage in the model, a failure can be attributed, waived or fixed one component at a time. Partial dispositions stop being a spreadsheet exercise.
Today: a finding points at one part_id whose refDes is a string covering many components. Waiving "C24 but not C47" has nowhere to live.
3
metadata def — waivers attach to the element
A waiver is domain vocabulary added through KerML metadata rather than a stereotype or a side table. It rides with the part through export, API read and document generation.
Today: the waiver table is complete and well-modelled — requester, reason, risk assessment, mitigation, reviewer, decision. It simply does not leave the database with the part it excuses.
4
connect — applied stress has provenance
The single most common review question about a derating failure is "where does that number come from?". With ports and connections in the model, the answer is a traversal rather than a conversation with whoever built the spreadsheet.
Today: actualVoltage and actualPower are asserted values with no modelled source. This is the largest genuine gap in the current schema.
5
Coverage as a query, including the negative result
Because constraints declare their subject type, the set of rules with nothing to bind to is computable. "We checked everything applicable, and here is what was not applicable and why" is a much stronger assurance claim than a list of passes.
Today: coverage is inferred from which findings exist. A rule that never fired is indistinguishable from a rule that was never considered.
