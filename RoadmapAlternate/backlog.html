Sequencing Principles

  • Security gates are non-negotiable. P0-01 and P0-04 are complete — P0-02, P0-03 (in progress), P0-05, and P0-06 (not started) must close before any customer data enters the system.
  • Staging before prod. P0-02 must be live before any Phase 1 work touches infrastructure.
  • Metering before billing. P1-02 is a hard dependency of P1-10 — do not integrate Stripe until metering is validated for ≥2 billing periods.
  • Compliance is a long game. Start SOC 2 readiness (P1-12) in Phase 1 so the report (P2-01) arrives in Phase 3 when enterprise contracts need it.
  • QMS is Phase 3+. It requires the core platform to be stable and has its own dedicated design/build cycle.
